# Week 1 – Grade Calculator

My first Python project, built during Week 1 of a 12-week Python learning plan.

## What It Does
Takes a number of marks as input, validates them, calculates the average, and assigns a letter grade (A–F).

## What I Learned
- Variables, data types, operators
- String methods and slicing
- `input()` and typecasting
- `if / elif / else` conditionals
- `while` loops and `try/except` error handling
- Basic Git (init, add, commit, push)

## How to Run
```bash
python day6_find_grade.py
